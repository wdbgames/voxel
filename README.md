## CONTROLS
* WASD to move
* Q and E to move up and down
* NUMBER KEYS to change inventory slot
* SCROLL or ARROWS to change selected item
* SPACE TO JUMP
* LEFT CLICK to destroy tiles
* RIGHT CLICK to place tiles
* MIDDLE CLICK to pick tile
* F + 1 to toggle debug
* F + 2 to toggle fly
* F + 3 to toggle noclip
* F + 4 to increment near distance
* F + 5 to increment far distance
